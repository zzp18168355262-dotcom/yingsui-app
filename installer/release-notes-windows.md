Windows 版下载。两个文件，功能完全一样，只是打包方式不同。

## 安装版（推荐，给普通用户）

下载 **`EnglishCorner-<版本>-windows-x64-setup.exe`**，双击安装。

- 自动添加开始菜单入口，桌面快捷方式可选
- 默认按当前用户安装，**不会弹管理员密码**
- 想卸载：设置 → 应用 → 英语角 English Corner

## 绿色版（免安装）

下载 **`EnglishCorner-<版本>-windows-x64.zip`**，解压到任意文件夹，双击 `yingsui.exe` 即可。

注意要**整个文件夹一起用**，不要只把 exe 单独拷出来 —— 它依赖同目录的 DLL、`data\` 和 `ffmpeg\`。

## 第一次打开会被 Windows 拦一下

本项目没有购买代码签名证书，所以安装包和主程序都没有数字签名。
首次运行会弹「Windows 已保护你的电脑」：

> 点「**更多信息**」→「**仍要运行**」

放行一次之后就不会再问了。

## 系统要求

- 64 位 Windows 10（1809）或更高
- 首次使用跟读/听写功能时，Windows 会询问麦克风权限，需要允许
